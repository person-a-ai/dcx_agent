## Behavior

Initial selection follows bars.targets[0], default_target, then the first item. Paging follows the viewed insight revision's item order. Missing selections display the first item, and current-data reload/poll results normalize removed selections to the first current item.

The default chat target resolves to insight:<current id>; insight targets follow paging. List and concept targets retain their scope. InsightChatBar always receives a focusId matching its target ID (or the current item for the list target). Only list chat supplies actions.chat with the third focus-ID argument.

Insight and list targets share insight revision history. Insight previews use radarMean(viewed.items), never the current summary mean or current per-item radar fallback. Current revisions use summary.radar_mean. Preview confirmation, chat, rederivation, and concept creation controls are disabled; the insight pager remains available.

Fresh derivation calls startInsight(sid, {mode:'derive', fresh:true}, version), then records the returned runId as pending. The existing InsightHeader confirmation dialog is reused. Readonly, busy, pending, running, and preview states disable rederivation.
