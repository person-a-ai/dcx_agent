# 키워드 일괄 입력 — 기획

## 문제
- 1단계(키워드)에서 사람이 넣는 키워드는 하위분류 그룹의 "직접 추가하기"로 **한 번에 1개씩**만 넣을 수 있다(`POST /keywords/{sid}/manual` → `rounds.add_manual`).
- 고객사 자료·데스크 리서치 등으로 이미 CSV나 리스트로 정리된 키워드(수십~수백 개)가 있어도 하나씩 그룹을 찾아 입력해야 한다.
- 이 리스트에는 축·하위분류가 **있을 수도, 없을 수도** 있다. 지금 시스템은 축·하위분류가 없는 키워드를 저장할 수 없다(커버리지 계산, 크롤 문서의 `kw_axis`·`kw_sub`, 축 탭·그룹 화면이 모두 이 값을 쓴다).

## 사용자 결정
- 분류가 없는 행은 **B안: LLM이 축·하위분류를 제안하고, 추가 전 미리보기에서 사람이 확인·수정**한다. (2026-10-28 대화: "B안으로 진행해줘")
- 대안 A(전체를 한 그룹으로 지정)는 섞인 리스트에 맞지 않고, C(미분류 칸)는 크롤·커버리지가 깨져 주 방식에서 제외. A는 미리보기의 보조 동작("모두 이 그룹으로")으로만 둔다.

## 동작 (예시)
1. 키워드 화면에서 "일괄 추가하기"를 누른다.
2. 리스트를 붙여넣거나(줄바꿈·쉼표·탭 구분, 엑셀에서 복사한 표 포함) CSV 파일을 올린다.
3. 첫 줄에 `키워드/kw`, `축/axis`, `하위분류/sub` 머리글이 있으면 열로 인식한다. 축·하위분류 값은 코드(`psychological`, `emotion`)와 화면 이름(`심리`, `감정`) 모두 받는다.
4. 분류가 있는 행은 그 값을 쓰고, 없는(또는 인식 못 한) 행만 LLM이 프로젝트 맥락을 보고 분류를 제안한다.
5. 미리보기 표: 키워드 · 분류(수정 가능) · 분류 출처(입력값/자동 제안) · 상태(추가 예정 / 이미 있음 / 리스트 안 중복 / 분류 필요).
6. 행을 빼거나 분류를 고친 뒤 "N개 추가하기" → 추가 결과(추가 N · 건너뜀 M과 이유)를 보여준다.
7. 추가된 키워드는 지금의 직접 추가와 같다(`origin: manual`, 승인 상태, 검색량 조회, 이벤트·피드백 기록). 이후 드래그·M키로 이동할 수 있다.

## 수용 기준
- AC1: 붙여넣기 텍스트(줄바꿈·쉼표·탭 구분)와 CSV 파일(UTF-8, UTF-8 BOM, CP949)을 받는다. 빈 줄·앞뒤 공백은 무시한다.
- AC2: 머리글이 있으면 키워드·축·하위분류 열을 인식하고(한글·영문 이름), 머리글이 없으면 첫 열을 키워드로 본다.
- AC3: 축·하위분류 값은 코드와 화면 이름을 모두 인식한다. 인식 못 한 값은 "분류 없음"으로 보고 자동 제안 대상에 넣는다.
- AC4: 분류 없는 행은 LLM이 기존 축·하위분류(사용자 정의 `custom:` 포함) 중 하나를 제안한다. LLM이 실패하거나 목록 밖 값을 내면 그 행은 "분류 필요"로 남고 사람이 고르기 전까지 추가되지 않는다.
- AC5: 미리보기에서 행별 분류 변경, 행 제외, "모두 이 그룹으로" 일괄 지정을 할 수 있다.
- AC6: 기존 키워드와 정규화 키가 같은 행은 "이미 있음", 리스트 안에서 겹치는 행은 첫 행만 남기고 "리스트 안 중복"으로 표시하며 추가하지 않는다.
- AC7: 추가 시 결과를 행별로 돌려준다(추가됨 / 중복 / 분류 오류). 일부 실패가 나머지 추가를 막지 않는다.
- AC8: 추가된 키워드는 단건 직접 추가와 같은 형태로 저장된다(`origin: manual`, `approved`, 검색량, `add` 이벤트, 피드백 md). 검색량 조회는 한 번에 묶어서 한다.
- AC9: 한 번에 최대 500행. 넘으면 앞 500행만 받는다는 안내를 보여준다.
- AC10: 읽기 전용 버전·다른 버전 활성·편집 불가 상태에서는 기존 단건 추가와 같은 오류로 막는다.
- AC11: 백엔드 pytest · 프런트 lint · build · test 통과.

## 제외 범위
- 엑셀(.xlsx) 파일 직접 업로드(엑셀 표는 복사-붙여넣기로 지원).
- 외부 크롤 결과 일괄 투입(별도 기능).
- 리스트에서 새 하위분류를 자동 생성하는 것(인식 못 한 하위분류 이름은 "분류 없음" 처리; 사용자 정의 하위분류는 기존 화면에서 먼저 만든다).
- 일괄 추가 되돌리기 버튼, 추가 이력 화면.

## 위험
- LLM 분류 오답 → 미리보기에서 출처(자동 제안)를 표시해 사람이 확인하게 하고, 추가 후에도 이동 가능.
- 500행 분류의 대기 시간·비용 → 분류 없는 행만 보내고, 묶음(예: 100개) 단위로 나눠 요청한다.
- 한국어 엑셀 CSV의 CP949 인코딩 → UTF-8 실패 시 CP949로 다시 읽는다.
- 일괄 추가 중 다른 편집과 충돌 → 기존 세션 잠금 안에서 한 번에 저장한다.

## 설계 필요 여부
- 필요. 새 입력·미리보기 화면(상태별 행, 수정·제외, 로딩·오류·빈 상태, 모바일)과 새 API 2개(분류 제안, 일괄 추가)가 생긴다.
