# 계획 보완 1 — 일괄 입력 파싱: 따옴표는 한 줄 안에서만 (2026-10-28)

- 대상: [03-plan.md](03-plan.md) Task T3, Review Focus 1. 03-plan.md 본문은 승인 해시 보존을 위해 고치지 않고 이 문서로 보완한다.
- 사유: T3 독립 리뷰 2회 FAIL. 승인된 규칙 ① "따옴표 셀은 줄바꿈을 포함할 수 있다"와 ② "닫히지 않은 따옴표는 그 줄 끝에서 끊는다"가 서로 충돌해 모호한 입력마다 새 반례가 나왔다(리뷰 로그 `.harness/reviewer-T3.log`, `.harness/reviewer-T3-r2.log`).
- 사용자 결정(대화 원문): 파싱 규칙 질문에 "줄 단위로 단순화 (Recommended)", 기록 방식 질문에 "계획 보완 문서로 기록 (Recommended)".

## 바뀐 규칙

1. 입력은 먼저 줄바꿈(`\r\n`, `\n`, `\r`)으로 행을 나눈다. 줄바꿈은 따옴표 안에 있어도 항상 행 구분이다.
2. 각 줄 안에서만 따옴표를 해석한다: 셀 시작의 `"`가 따옴표 셀을 열고, `""`는 따옴표 한 글자, 셀 안의 쉼표·탭은 글자로 남는다.
3. 같은 줄에서 닫히지 않은 따옴표는 여는 따옴표를 버리고 줄 끝까지를 한 셀로 본다.
4. 구분자 판정: 위 규칙으로 따옴표 밖에 있는 탭이 텍스트 어디에든 하나라도 있으면 탭, 아니면 쉼표.

## 바뀐 테스트 기대값 (T3)

- `parses excel paste with quotes and trailing tabs`: `'"a, b"\t심리\t감정\t\t\n"줄\n바꿈"\t\t'` → `[{kw:'a, b',axis:'psychological',sub:'emotion'},{kw:'줄'},{kw:'바꿈'}]` (엑셀 셀 안 줄바꿈은 두 키워드로 나뉜다. 미리보기에서 보이고 제외할 수 있다).
- 추가 회귀 테스트(리뷰 반례):
  - `'"abc\n"소음",물리,감각\n환기'` → `abc` / `소음`(physical·sense) / `환기`.
  - `'"abc\n소음,"물리",감각\n환기'` → `abc` / `소음`(physical·sense) / `환기`.
  - `'kw,axis,sub\n"abc\n""def""",physical,sense'` → 결과 행이 정확히 2개, 첫 행 kw가 `abc`(닫히지 않은 따옴표 → 줄 끝까지). 둘째 행은 독립 줄로 해석되고 axis·sub가 `physical`·`sense`로 인식된다(둘째 행 kw 값은 구현의 따옴표 규칙대로 고정해 단언).
- 리뷰 3회차 반영(같은 규칙의 귀결): 셀 시작이 아닌 따옴표는 글자로 보존한다(`27" 모니터` 유지). 따라서 위 엑셀 붙여넣기 예의 둘째 키워드는 `바꿈"`이 된다(줄 단위 규칙상 닫는 따옴표만 남은 줄). 미리보기에서 보이고 제외할 수 있다.
- 머리글 별칭: 하위분류 열은 `하위분류`·`하위 카테고리`·`sub`·`subcategory`, 키워드 열은 `키워드`·`kw`·`keyword`, 축 열은 `축`·`axis`.
- 나머지 T3 테스트(`unterminated quote ends at line end`, `quoted tab does not switch delimiter` 등)는 그대로 유지.
