# UAT 수정: Opportunity Map을 DCX 1.0 산식·그림에 맞춤

근거: DCX 1.0 결과물 PDF(커밋 65e5b14, GS건설 보고서) 199~200쪽과 `resources/DCX_1.0_원본프로세스_상세.md` STEP 10-B.
- 축은 선형(중요도·만족도 모두 세션 최소~최대 정규화). 사선①은 (0, S 평균)→(1,1), 사선②는 (I 평균, 0)→(1,1), 가로선은 축 가운데(0.5). 구역 판정 기하는 지금 코드와 같다.
- 중요도 = 언급량: `CS_k = Σ_docs 토픽 비중`(세션 전체), 그다음 min-max.
- 만족도: 사용자 결정으로 지금처럼 문서 감성 평균((s+1)/2) 유지.

## 변경
1. 프론트엔드: `OpportunityMap`의 로그 눈금을 선형으로 되돌린다. `zoneRegions` 꼭짓점도 선형 좌표로 그린다(사선이 직선). 눈금은 0, 0.25, 0.5, 0.75, 1. 쓰지 않는 `logScale`·`LOG_TICKS`는 삭제하고 테스트를 맞춘다. 라벨 경계 뒤집기·겹침 회피는 유지.
2. 백엔드: `backend/app/evidence/assemble.py _raw_metrics`의 중요도를 `sum(theta)`(페르소나 문서 수로 나누지 않음)로 바꾼다. theta가 없으면 None. min-max 정규화와 ODI 산식은 그대로.
3. 만족도 산식은 바꾸지 않는다.
