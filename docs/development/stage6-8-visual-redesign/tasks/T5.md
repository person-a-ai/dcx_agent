## 범위 및 차이
- CSS는 두 컴포넌트에서 직접 import했다. App Router이므로 페이지 import 우회는 하지 않았다.
- 기본 빌드 정체로 Webpack 검증을 추가했다. 브라우저 시각 검증은 수행하지 않았다.
- `PersonaScreen.tsx`, 페이지, backend는 수정하지 않았다. 기존 backend/T1 변경은 그대로 두었다.
- 화면 연결은 T8에서 수행한다. git 쓰기 명령은 실행하지 않았다.
