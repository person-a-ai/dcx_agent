# T7 · 구조 트리와 기회 순위

구현 완료. 전체 GREEN은 수정 범위 밖의 기존 SVG 단언 1건 때문에 달성하지 못했다.

- 설계 3.4-4, 3.6을 먼저 읽고 구현했다.
- HierarchyTree를 SVG에서 중첩 ul로 변경했다. 루트는 항상 열리고, expandedId가 속한 경로만 기본으로 펼친다. 클러스터·페르소나는 aria-expanded 버튼으로 접고 펼친다. 각 행에 전체 트리 최대 문서 수 대비 data-ratio 막대와 문서 수를 표시한다.
- OpportunityBars를 순위·줄바꿈 문장·막대·값의 4칸 HTML 그리드로 변경했다. data-mean 평균선은 각 막대 영역 안에 배치했다. 기존 props, 내림차순 정렬, null과 0 구분을 유지했다.
- persona.css는 규칙을 추가만 했다. 기존 색상 토큰을 사용하고 토글 버튼 최소 높이를 44px로 설정했다.
- 지정된 프론트엔드 파일 4개와 이 보고서만 수정했다. backend와 기존 호출자는 수정하지 않았고 git 쓰기 명령도 실행하지 않았다.
