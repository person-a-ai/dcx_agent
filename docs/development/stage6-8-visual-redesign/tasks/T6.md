# T6 — Context 비교 표

완료. `02-design.md` 3.4-2(7A), 표면 규칙 4A, 6절(6A)을 반영했다.

- 행 순서: 행동 → 상태 → 감정 → 장벽 → 페인포인트 → 키워드 → 쓰는 제품·수단 → 만족도 → 기회 → 근거 수.
- `CCMCell.more?: number`의 양수 값을 `+N`으로 표시한다.
- `ccm-clamp`로 문장을 3줄까지 표시하고, 칸을 누르면 전체 문장과 전달된 근거를 펼친다. 여러 페인포인트의 전체 내용은 기존 `evidence` 슬롯으로 제공한다.
- 누락·빈 문자열·공백 문자열 칸은 `ccm-empty`의 “근거 부족”으로 표시한다.
- `ccm-scroll` 가로 스크롤, `ccm-sticky` 행 머리 고정 및 `--paper` 배경, 768px 미만 열 최소 200px, 오른쪽 스크롤 음영, 칸 버튼 최소 높이 44px를 추가했다.
- 기존 `foldColumns`, 관측/추론 표시, 반례 표시, 키보드 버튼 동작과 근거 연결을 유지했다. 표는 `ds-tbl`만 사용하며 바깥 카드 상자는 추가하지 않았다. CSS는 기존 규칙 뒤에만 추가했고 기존 토큰만 사용했다.
- `PersonaScreen.tsx`와 backend는 수정하지 않았다. 현재 `CCMTable`/`ccmRows` 사용과 타입 호환을 유지했다. 화면의 새 행 데이터 매핑은 T8 범위다. git 쓰기 명령은 실행하지 않았다.
