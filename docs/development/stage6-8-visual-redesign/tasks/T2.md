# T2 — 카드 생성에서 Context·페르소나 페인포인트 만들기

상태: 지정 범위 구현 완료. 대상 테스트 GREEN. 전체 테스트는 소유 범위 밖 정적 픽스처 불일치 1건으로 미통과.

## 변경 파일

- `backend/app/persona/cards.py`: PainCell·ContextOut 스키마, Context 소속 인용 검증, 근거 payload의 pain_point, R2 cite 기반 dims 문장 유지/원문 대체, R4 관측/추론·source_pain, 전역 E 번호 변환, 빈 Context 처리, null 장벽 보충, 정규화 중복 병합·정렬·상위 5개 집계.
- `backend/app/persona/prompts/card.v1.md`: pain_points 출력 및 태그 우선·유사 문장 병합·태그 없을 때 근거 인용으로 작성·인용 필수·근거 없을 때 빈 배열 지시.
- `backend/app/persona/grade.py`: pain_point trace 추가. 기존 등급 계산·지원 비율 대상에는 포함하지 않음.
- `backend/tests/fixtures/evidence_package.py`: 가짜 backend의 응답 helper에 근거 있는 Context별 `가짜 불편`과 첫 근거 인용 추가.
- `backend/tests/persona/test_cards.py`: 계획 Step 1 및 R2/R4 회귀, 최대 3개, 후속 청크 인용 변환, 여러 인용 중 일치 태그 선택 테스트.
- `backend/tests/persona/test_grade.py`: pain_point trace와 기존 등급·지원 비율 불변 검증.

## 전체 검증

```sh
backend/.venv/bin/python -m pytest backend/tests -q -n 6
```

- 최초 실행: `1 failed, 2771 passed, 13 warnings in 142.60s`.
- 추가 테스트까지 포함한 최종 실행: `1 failed, 2775 passed, 12 warnings in 141.23s` (exit 1).
- 실패: `backend/tests/persona/test_package.py::test_fake_responses_use_actual_references`.
- 원인: 테스트가 가짜 backend 응답과 `backend/tests/fixtures/llm/persona.card.json`을 완전히 비교한다. 새 응답에는 Context별 pain_points가 있지만 정적 JSON에는 없다.
- 필요한 후속 변경: 정적 JSON의 C0/C1/C2에 각각 `pain_points: [{"text": "가짜 불편", "cite": ["E2"]}]`, E6, E10을 추가해 동기화한다.
- 변경한 소유 파일의 `git diff --check` 통과.

## 편차·범위

- 정적 JSON은 사용자 지정 소유 파일 밖이므로 수정하지 않았다. 전체 테스트 GREEN은 해당 픽스처 동기화가 남아 있다.
- 집계의 Context 문서 수 정렬은 병합된 고유 context_ids의 doc_count 합계를 사용한다. 완전 동률은 입력 순서를 유지한다.
- null 장벽은 LLM 원래 값으로 판단해 첫 페인포인트로 보충한다. dims fallback으로 null이 가려지는 것을 방지했다.
- frontend, T1 계약 모델, 운영 데이터는 수정하지 않았으며 git write 명령은 실행하지 않았다. 사용자 지시에 따라 커밋하지 않았다.

## Fixture sync

- `backend/tests/fixtures/llm/persona.card.json`의 각 Context에 `pain_points: [{"text": "가짜 불편", "cite": [...]}]`를 추가했다. 기존 인용 형식을 유지하며 C0는 E2, C1은 E6, C2는 E10으로 각 Context 자체 근거를 인용한다.
- RED: `backend/.venv/bin/python -m pytest backend/tests -q -k test_fake_responses_use_actual_references` → `1 failed, 2778 deselected, 1 warning in 4.89s` (exit 1). 정적 픽스처에 pain_points가 없어 가짜 backend 응답과 불일치했다.
- GREEN: 같은 명령 재실행 → `1 passed, 2778 deselected, 1 warning in 4.55s` (exit 0).
- Persona 검증: `backend/.venv/bin/python -m pytest backend/tests/persona -q` → `333 passed, 2 warnings in 19.09s` (exit 0).
- 전체 검증: `backend/.venv/bin/python -m pytest backend/tests -q -n 6` → `2776 passed, 12 warnings in 149.60s (0:02:29)` (exit 0).
- 앞서 기록한 정적 픽스처 불일치를 해결하여 전체 테스트 GREEN. 테스트를 약화하지 않았고, 이번 수정은 지정된 JSON과 이 보고서에 한정했으며 git write 명령은 실행하지 않았다.
