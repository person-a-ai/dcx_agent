## 구현

- T3의 `logScale`, `LOG_TICKS`, `zoneRegions`, `jitter`를 그대로 재사용했다. T3 파일은 수정하지 않았다.
- 구역 레이어 `ZoneLayer`에서 전달받은 `map.base`를 `base`로 받아 `useMemo(() => zoneRegions(base), [base])`로 계산한다(R8).
- 6개 `data-zone` 다각형과 내부 구역 이름을 표시한다. 면색은 F=`--danger-soft`, C=`--warning-soft`, 나머지=`--sunken`; 이름은 F=`--danger`, C=`--warning`, 나머지=`--sub`이다.
- 축과 점 및 128구간으로 샘플링한 점선 기준선을 로그 좌표로 변환했다. 원래 값 눈금과 ‘로그 척도’를 표시한다.
- 점 라벨은 highlighted Context에만 표시한다. 선택 페르소나는 파란색, focus 대상 외 페르소나는 opacity 0.25이다.
- 클러스터당 버튼 하나로 해당 클러스터 전체를 토글한다. 페르소나별 버튼은 제거했다.
- null 좌표 점은 생략하고 지정된 안내 문구를 표시한다. 겹친 점은 Context ID 순으로 결정적 jitter를 적용한다.
- 툴팁은 원래 중요도·만족도·기회 값과 겹친 개수를 표시한다. SVG는 600×420, 최소 높이 320px이다.
- 기존 props와 콜백을 유지하고 `focusPersonaId`, `compact`를 추가했다. 기존 토큰만 사용했다.

## 조정 및 제한

- 기존 직접 함수 호출 테스트가 React `useMemo`를 mock하지 않아, 구역 계산을 같은 파일의 자식 컴포넌트로 분리했다. 실제 React 렌더링에서 memo가 동작하며 별도 테스트 파일은 수정하지 않았다.
- 기존 PersonaScreen 테스트 호환성을 위해 클러스터 버튼의 aria-label에 해당 클러스터의 Persona ID 목록을 유지했다. 버튼 수와 토글 동작은 클러스터 단위이며, title에 Persona 이름 목록을 제공한다.
- 명시된 동작 계약에 따라 라벨은 highlighted 점에만 표시한다. selected/focus만으로 점 라벨을 추가하지 않는다.
- 퇴화하여 면적이 없는 구역에는 내부 이름을 배치하지 않는다. 6개 다각형 요소는 유지한다.
- 브라우저 시각 QA는 수행하지 않았다. SSR 출력·React 요소 핸들러 테스트로 검증했다.
- backend 파일은 수정하지 않았으며 git 쓰기 명령은 실행하지 않았다. 동시 작업자의 backend 변경은 그대로 두었다.
