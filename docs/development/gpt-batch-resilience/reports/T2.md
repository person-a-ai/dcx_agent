## 정지·중단 반응 주의점

요청된 모듈 `time.sleep(_capacity_wait(k))`는 동기 대기이며 정지 플래그를 polling하지 않는다. 기본 2회 대기는 합계 15~21초(각각 5~8초, 10~13초); 재시도를 많이 설정하면 회당 최대 33초까지 대기한다. 따라서 대기 중 정지 요청에 즉시 반응하는 보장은 없고, 추가 fake/실제 worker 실행 시간도 별도이다. judge_batch에는 중단 callback 인터페이스가 없어 이 작업 범위에서는 취소 구조를 변경하지 않았다. 즉시 중단 보장이 필요하면 호출자 취소 신호를 연결하는 후속 작업이 필요하다. 재시도 0 설정은 추가 대기를 없앤다.
