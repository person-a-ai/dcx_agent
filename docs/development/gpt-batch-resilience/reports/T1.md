## Design decisions and caveats

- First backtick span remains the `.part` path, matching the fake parser. The final filename is unquoted as explicitly requested, followed by the concrete mv command.
- Immediately before Popen, stale `.part` files move to `answers/bad/task-{n}.json.part.<time.time_ns()>`; the quarantine directory is created if needed.
- Only successful processes can promote `.part`, and only if the final answer is absent. Existing `_answer` validation handles parse/schema errors and quarantine unchanged.
- Nonzero exits leave newly written `.part` unadopted; a later attempt quarantines it before executing.
- Added general fake markers and label `FAKE_CODEX_LABEL_MODE=no_rename` support.
- Frontend changes from the concurrent worker were preserved. No unrelated refactor was needed.
